# SkillGate 主动性能力总结

## 主动性的四个层次

| 层次 | 说明 | 我们达到了吗？ |
|------|------|-------------|
| 1. 被动执行 | 用户说什么做什么 | ✅ 做到了 |
| 2. 主动建议 | 用户没说，但是主动提醒 | ✅ 做到了 |
| 3. 主动执行 | 用户没说，但是主动做一些小事 | ✅ 做到了 |
| 4. 完全自主 | 自己定目标，自己做 | ❌ 做不到（我们是工具，目标是用户定的） |

→ **我们达到了第 3 层（主动执行），是本地工具能做到的最高水平。**

---

## 主动性的四大维度

| 维度 | 说明 | 对应模块 |
|------|------|----------|
| **用户行为驱动** | 从使用历史推断需求，主动推荐 | `proactive_recommender.py` |
| **外部事件驱动** | 感知环境变化，文件变了自动扫 | `file_watcher.py` |
| **内部不确定性驱动** | 自我反思，发现问题就改 | `self_evolution.py` |
| **预期，不只是反应** | 预测用户需要什么，提前做 | `proactive_recommender.py` |

→ **四大维度全部覆盖。**

---

## 主动性闭环完整流程

```
👀 主动监控（proactive_monitor.py）
   检查系统状态：错误队列、成功率、成本
        ↓
💡 主动推荐（proactive_recommender.py）
   从使用历史推断需求，推荐 skill
        ↓
🔮 主动预测（proactive_recommender.py）
   预测用户接下来可能需要什么
        ↓
👁️ 文件监控（file_watcher.py）
   感知环境变化，文件变了自动扫
        ↓
🧬 自我诊断（self_evolution.py）
   分析数据，发现问题
        ↓
⚡ 主动执行（proactive_executor.py）
   自动做维护：重试失败任务、清理缓存、归档 traces
        ↓
🛠️ 自动改进（auto_improve.py）
   尝试改进：建议改进路由匹配
        ↓
📊 记录数据
   traces / analytics / cost
```

---

## 一键跑所有主动性功能

```bash
python ecosystem.py proactive
```

这一个命令就会跑全部 5 步：
1. 主动监控（检查系统状态）
2. 主动推荐（推荐 skill）
3. 文件监控（检查文件变化）
4. 主动执行（自动做维护）
5. 自我进化（给出改进建议）

---

## LGD 三律对应

| LGD 三律 | 对应主动性的什么 |
|----------|-----------------|
| **有籍（registered）** | 每次主动检查、主动执行都有记录 |
| **有证（evidenced）** | 主动推荐、主动预测都有数据证据（从 analytics 学） |
| **有门禁（gated）** | 主动监控发现问题就提醒，主动执行做维护 |

→ **主动性完全符合 LGD 三律。**
