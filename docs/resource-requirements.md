# SkillGate 资源要求说明

## 💻 最低硬件要求

| 资源 | 最低要求 | 说明 |
|------|----------|------|
| CPU | 任何 64 位处理器 | 纯文本处理，几乎不耗 CPU |
| 内存 | 512 MB | 扫描一个 skill 目录，占用 < 100 MB |
| 磁盘 | 50 MB | 整个项目 + 所有依赖 |
| 网络 | **不需要** | 100% 离线可用 |

---

## 📦 软件要求

| 软件 | 最低版本 | 说明 |
|------|----------|------|
| Python | 3.8+ | 只要有 Python 就能跑 |
| 第三方依赖 | **0 个** | 纯标准库，pip install 都不用 |

### 为什么这么轻？

- ✅ 纯正则 + AST 分析，不用 ML 模型
- ✅ CVE 数据库内置，不用联网下载
- ✅ 所有工具都是单文件脚本
- ✅ 没有数据库，没有服务器，没有缓存服务

---

## 📴 离线可用吗？

**100% 离线可用。**

| 功能 | 离线能用吗 |
|------|-----------|
| 安全扫描 | ✅ 完全离线 |
| Trust Score 计算 | ✅ 完全离线 |
| SBOM 生成 | ✅ 完全离线 |
| SLSA 分级 | ✅ 完全离线 |
| Scorecard 评分 | ✅ 完全离线 |
| 审计日志 | ✅ 完全离线 |
| 报告生成（HTML/SVG） | ✅ 完全离线 |
| LLM-as-judge | ⚠️ 需要 API key（可选） |

**只有一个功能需要联网：** LLM-as-judge（用大模型评测输出质量）。其他所有功能都离线可用。

---

## 🆚 和竞品比资源要求

| 工具 | 安装大小 | 内存占用 | 离线可用 |
|------|----------|----------|----------|
| **SkillGate** | ~5 MB | < 100 MB | ✅ 100% |
| Semgrep | ~100 MB | ~500 MB | ⚠️ 部分规则要下载 |

**我们是最轻的。**

## 🚀 快速验证

```bash
# 下载下来直接跑，不用 pip install
python skillgate.py scan ./my-skill/
```

没有 `requirements.txt`，没有 `pip install`，没有 `npm install`，解压就能用。

## 🏁 结论

| 问题 | 答案 |
|------|------|
| 软件要求最低吗？ | ✅ 只要 Python 3.8+，零第三方依赖 |
| 硬件要求最低吗？ | ✅ 512MB 内存就能跑 |
| 离线可用吗？ | ✅ 99% 功能离线可用（只有 LLM 评测要联网） |

**这就是"本地优先"的真正含义：不用装一堆东西，不用联网，解压就能跑。**
