# 医械法规技能族（Medical Device Regulatory Skill Family）

> 一套本地运行的医械法规文档检查工具——13 个 skill，覆盖医械法规的主要方面。

---

## 🎯 什么时候用？

| 场景 | 用哪个 skill？ |
|------|---------------|
| 你刚写完一份医械文档，要提交给监管机构前 | ✅ 全部都跑一遍 |
| 你写的是 IFU（使用说明书） | ✅ `ifu-labeling-check` |
| 你写的是风险管理文件 | ✅ `iso14971-risk-matrix` |
| 你写的是软件相关的文档 | ✅ `iec62304-sdlc-check` |
| 你做的是医疗 AI 产品 | ✅ `ai-medical-algorithm-check` + `ai-dataset-quality-check` |
| 你不知道该跑哪些检查 | ✅ `medical-recommender.py` 自动推荐 |

---

## 🚀 怎么用？

### 1. 单个检查
```bash
python ifu-labeling-check.py 我的说明书.md
```

### 2. AI 推荐
```bash
python medical-recommender.py 3   # 第 3 类（高风险）
```

### 3. 一键跑全部（技能链）
```bash
python medical-device-chain.py 我的文档.md 3
```

### 4. 自动生成 HTML 报告
跑完技能链后，自动生成 `scan-report.html`——打开浏览器就能看。

## 📊 用完有啥效果？

| 改善前（不用） | 改善后（用了） |
|---------------|---------------|
| 写完文档直接提交，被监管打回来 | 提交前先自查，提前发现问题 |
| 不知道缺什么，漏了就漏了 | 一目了然——缺什么、应该怎么写 |
| 靠人工一条一条对照标准 | 自动检查，几秒就扫完 |

→ **效果：提交前先自查，减少被打回来的次数。**

---

## 🎯 准确率怎么样？

**诚实告诉你：**
- 我们是**关键词匹配**，不是真理解文档
- 准确率大概 **70-80%**
- 优点：快、简单、零依赖
- 缺点：有误报、漏报——最终还是要人工判断

→ **这不是万能的——这是"初筛工具"，不是"最终判决"。**

---

## 📜 数据是否可信、权威？

**是！** 我们的规则都是从这些标准里来的：
- ISO 14971（风险管理）
- ISO 13485（质量管理体系）
- IEC 62366（可用性工程）
- IEC 62304（软件生命周期）
- ISO 10993（生物相容性）
- EU MDR 2017/745
- NMPA 相关指导原则

→ **规则是权威的——但是检查结果要人工判断。**

## ❓ 常见问题（FAQ）

**Q1: 这个工具能代替人工审核吗？**
A: 不能。这是**初筛工具**，不是最终判决——最终还是要人工判断。

**Q2: 准确率多少？**
A: 大概 70-80%——关键词匹配，有误报、漏报。

**Q3: 我的文档是中文的，能检查吗？**
A: 能——我们的关键词里有中文和英文，双语都支持。

**Q4: 支持哪些文件格式？**
A: 现在只支持 `.md`（Markdown）——其他格式要先转成 Markdown。

**Q5: 会不会把我的文档上传到云端？**
A: 不会——全部本地运行，不联网，不上传。

**Q6: 规则是最新的吗？**
A: 规则基于 ISO 13485:2016、ISO 14971:2019 等现行标准——但是标准会更新，建议定期检查。
